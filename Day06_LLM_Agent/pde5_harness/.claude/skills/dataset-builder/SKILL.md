# dataset-builder

## 언제 사용하는가
`chembl-actives` 로 표적 활성물질이 있는 것을 확인한 뒤, 정량 분석용 데이터셋을 만들 때.

## 왜 층화하는가
상위 활성만 뽑으면 pIC50 범위가 1~2 로그에 그친다. 그 범위에서는 어떤 예측자도 기울기를
추정할 수 없고, 상관계수가 낮게 나와도 예측력 부족인지 범위 부족인지 구별되지 않는다.
**음성은 만들어낸 decoy 가 아니라 실측된 약한 활성**을 쓴다.

## 어떻게
```bash
python scripts/build_dataset.py --per-stratum 10
```
층: 강함 pChEMBL >= 7 · 중간 6~7 · 약함 < 6. 각 층에서 정렬 후 균등 간격으로 집는다.
결정적 규칙이라 시드가 필요 없고 같은 릴리스에서 같은 결과가 나온다.

## 반환 검증
- 세 층이 모두 채워졌는가
- 역가 범위가 3 로그 이상인가
- 중복 ChEMBL ID 가 없는가
- 전 화합물 SMILES 가 RDKit 로 파싱되는가
