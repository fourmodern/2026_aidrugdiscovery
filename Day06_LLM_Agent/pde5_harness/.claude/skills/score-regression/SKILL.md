# score-regression

## 언제 사용하는가
`docking-validation` 통과 후, 단일 점수가 역가를 예측하지 못할 때 항 재가중을 검정한다.

## 어떻게
```bash
python scripts/score_terms_regression.py
```
`smina --score_only` 로 자세별 항 값을 뽑아 pIC50 에 회귀한다.

## 반드시 함께 보고할 세 가지
학습 R² 만 보고하는 것은 소표본에서 무의미하다.

| 지표 | 왜 필요한가 |
|------|-------------|
| **Q² (leave-one-out)** | 새 화합물에 대한 예측력. 음수면 평균값 예측보다 못하다 |
| **라벨 섞기 R²** | y 를 무작위로 섞었을 때의 분포. 실제 R² 가 이 95 분위를 넘지 못하면 우연과 구별 불가 |
| **파라미터 수 대 표본 수** | n=30 에 파라미터 6개면 자유도가 위태롭다 |

## 해석 규칙
- R² 는 올랐는데 Q² 가 떨어졌다 → 과적합. 개선이 아니다
- 라벨 섞기 중앙값이 실제 R² 보다 높다 → 신호가 없다
- 상관 부호를 확인하라. 점수는 낮을수록 좋고 pIC50 은 높을수록 좋으니 **음의 상관이 양의 예측력**이다
