# binding-mode

## 언제 사용하는가
도킹 대조 통과 후. 점수가 낮다는 것과 자세가 화학적으로 타당하다는 것은 다른 문제이며,
그림은 후자를 보여준다.

## 어떻게
```bash
python scripts/render_binding_mode.py --compound <ChEMBL ID>
```
PyMOL 은 `-cq` 헤드리스로 구동한다. 세 장을 만든다.

| 그림 | 내용 |
|------|------|
| 전체 조망 | 수용체 카툰 + 결합 포켓 위치 + 결정 자세와 도킹 자세 |
| 포켓 근접 | 접촉 잔기 스틱 + 극성 접촉 거리 |
| 접촉 집계 | 4 Å 이내 잔기별 접촉 원자 수 (matplotlib) |

## 하드 규칙
- 접촉은 **좌표에서 직접 계산**한다. 도구가 내놓지 않은 상호작용을 그리지 않는다
- 라벨은 실제 접촉 잔기만. 전부 붙이면 글자가 겹쳐 읽을 수 없다
- 자세는 어느 규칙으로 골랐는지 캡션에 적는다 (점수 1위인지, 참조 기준인지)
- 그림이 예쁘다는 것은 결합이 강하다는 뜻이 아니다
