# exhaustiveness-sweep

## 핵심 원칙

재도킹 대조에서 1위 자세가 결정 자세와 멀 때, 원인은 둘 중 하나다.

- **탐색 부족** — 옳은 자세를 아예 만들어내지 못했다
- **채점 실패** — 만들어냈지만 점수가 그것을 1위로 올리지 못했다

처방이 정반대다. 전자는 탐색을 늘려야 하고, 후자는 탐색을 늘리면 **더 나빠진다** —
채점 함수가 결정 자세보다 좋게 평가하는 가짜 최소점을 더 많이 찾아내기 때문이다.

## 어떻게

같은 리간드·수용체·상자에서 `exhaustiveness` 만 바꾸고, 시드도 여러 개 쓴다.

```bash
python scripts/exhaustiveness_sweep.py --levels 4,8,16,32,64,128 --seeds 42,7,2024
```

## 읽는 법

| 관찰 | 진단 |
|------|------|
| 깊이↑ 에 C1·C2 모두 개선 | 탐색 부족이었다 — 깊이를 올려 해결 |
| 깊이↑ 에 C1 유지, C2 악화, 점수 개선 | **채점 실패** — 깊이를 올리면 역효과 |
| 깊이↑ 에 C1 도 개선 안 됨 | 상자·리간드 준비·수용체 상태를 먼저 의심 |

가운데 행이 이 하네스가 PDE5A 에서 실제로 관찰한 패턴이다.

## 하지 말 것

- 시드 하나로 판정하기 (도킹은 확률적이다)
- C1 과 C2 를 합쳐서 하나의 "RMSD" 로 보고하기
- 결과가 나쁘다는 이유로 깊이만 계속 올리기 — 원인 진단이 먼저다
