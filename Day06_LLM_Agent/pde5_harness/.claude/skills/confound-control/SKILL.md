# confound-control

## 핵심 원칙

**활성 화합물을 모아 점수와 역가의 상관을 재는 흔한 설계에는 구조적 교란이 있다.**

표적 구조는 대개 어떤 리간드가 결합한 채로 풀린 holo 구조다. 그 리간드를 닮은 화합물은
두 경로로 유리해진다.

1. 포켓에 기하학적으로 잘 맞아 **점수가 좋다**
2. 같은 계열의 최적화 산물이라 **대체로 더 강력하다**

두 경로가 같은 방향이므로 상관이 관찰된다. 그런데 그 상관은 채점 함수의 능력일 수도 있고
표적 구조 선택의 부산물일 수도 있다. **분리하지 않으면 어느 쪽인지 알 수 없다.**

## 언제 발동하는가

역가와 점수의 상관을 보고하려 할 때 **항상**. 예외 없다.

## 어떻게

### 1단계 — 설계로 분리한다 (가장 강함)

역가 구간과 **공결정 리간드와의 Tanimoto 유사도** 구간의 격자를 만들고 칸마다 균등 추출한다.

```bash
python scripts/build_controlled_dataset.py --per-cell 20
```

통과 기준: 역가-유사도 교란 상관 `|r| < 0.35`.

완전한 직교화는 화학적으로 불가능한 경우가 많다 (공결정 리간드와 매우 닮았는데 약한
화합물은 드물다). 남는 잔여 교란은 한계로 명시하고 2단계로 이중 확인한다.

### 2단계 — 통계로 통제한다

```bash
python scripts/analyze_controlled.py
```

세 가지를 **모두** 보고한다. 하나라도 빠지면 게이트 실패.

| 지표 | 무엇을 답하는가 |
|------|-----------------|
| 편상관 (Tanimoto 통제) | 골격을 고정했을 때 역가 신호가 남는가 |
| 유사도 구간 내 상관 | 각 골격 대역 안에서 따로 봐도 남는가 |
| 점수 ~ Tanimoto 상관 | 채점 함수가 골격 닮음에 직접 반응하는가 |
| **분자 크기 통제** | Vina 계열 점수는 중원자수와 상관된다 — 골격만 통제하면 부족하다 |
| 골격 + 크기 동시 통제 | 두 교란을 함께 제거했을 때도 남는가 (다변량 편상관) |

## 판정

- 편상관이 원상관의 60% 이상 유지 + p < 0.05 → 신호는 역가에서 온 것
- 크게 줄어듦 → 관찰된 성능은 상당 부분 골격 편향
- 구간내 상관이 구간마다 부호가 갈림 → n 이 부족하거나 신호가 없다

## 하지 말 것

- 전역 상관 하나만 보고하기
- "활성 화합물을 다양하게 모았다" 는 서술로 교란 통제를 대신하기
- 교란이 있다는 것을 알면서 "그래도 상관이 있으니 유용하다" 로 넘어가기
- Tanimoto 외 지문 하나만 써 놓고 골격 통제를 마쳤다고 하기 (지문 선택은 한계로 명시)
