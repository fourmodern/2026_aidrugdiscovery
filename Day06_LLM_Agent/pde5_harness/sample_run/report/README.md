# report — 연구 보고서 고정본

**연구 질문**: PDE5A 결정 구조에 대한 도킹 점수가 실측 IC50 을 예측하는가.
예측하지 못하면 점수 항을 재가중해 개선되는가.

**답**: 예측하지 못한다. 항 재가중도 개선을 주지 못하며 교차검증 기준으로는 악화된다.
다만 **실패 지점을 특정할 수 있었다** — 자세 생성이 아니라 채점이다.

## 핵심 수치

| 항목 | 값 |
|------|-----|
| 화합물 | 30건 (강함/중간/약함 각 10), pIC50 4.00–10.52 |
| 수용체 | PDB 1UDT (PDE5A + sildenafil, 2.3 Å) |
| C1 샘플링 대조 | 상위 모드 중 최선 RMSD 1.02 Å — 통과 |
| C2 채점 대조 | 1위 자세 RMSD 2.98 Å — 실패 |
| pIC50 vs 도킹 점수 | Spearman −0.498 |
| 단일 점수 회귀 | R² +0.144 · Q² +0.026 |
| 5개 항 회귀 | R² +0.121 · **Q² −0.545** |

Q² 가 음수라는 것은 새 화합물에 대해 평균값 예측보다 못하다는 뜻이다.
라벨을 섞었을 때의 R² 중앙값(+0.166)이 실제 적합값(+0.121)보다 높다.

## 읽는 순서

1. Figure 2 (재도킹 대조) — 결정 자세는 6·7번 모드에 1 Å 로 있는데 채점이 2.98 Å 를 1위로 골랐다.
   이 그림 하나가 연구의 출발점이다.
2. Figure 3 (점수 대 역가) — 예측력이 없다는 것을 눈으로 확인한다.
3. Figure 4 (회귀 비교) — 항을 늘리면 Q² 가 음수로 떨어진다.
4. Figure 8 (포켓) — 자세 자체는 화학적으로 타당하다. Gln817·Phe820 접촉.
