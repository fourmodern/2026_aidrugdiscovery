# report — 연구 보고서

이 디렉토리에는 **같은 연구의 두 판본**이 들어 있다. 판본이 나뉜 이유 자체가 이 하네스의
교육 자료이므로 구판을 지우지 않고 보존한다.

## 현행 — v3.0 도킹 연구 (n=163)

**「도킹 점수는 역가를 보는가, 골격을 보는가 — 골격 유사성을 설계로 분리한 PDE5A 재채점 연구」**

| 파일 | 내용 | 용도 |
|------|------|------|
| `report_controlled.md` | 본문 7,840단어 (IMRAD + 검증 로그 + 개정 이력 + 윤리) | 원본 |
| `docs/report_controlled.docx` · `_doc.pdf` | 논문 형식 문서 (27쪽) | 투고·회람 |
| `docs/poster_A0.pptx` · `.pdf` | **학회 포스터** A0 세로 841×1189 mm | 포스터 세션 |
| `docs/talk_16x9.pptx` · `.pdf` | **구두발표 덱** 13장, 발표자 노트 포함 | 12분 발표 |
| `figures_controlled/` | 그림 16장 (PNG + SVG) | 재사용 |

배포물은 셋뿐이다 — 문서 · 포스터 · 발표 덱. 보고서에서 자동 파생하던 슬라이드는 발표
덱과 목적이 겹치고 핵심 수치를 싣지 못해 제거했다. 서체는 Pretendard 로 통일했다.

**요지.** ChEMBL PDE5A 활성 전수에서 역가 3구간 × 공결정 리간드(실데나필) Tanimoto
3구간의 9칸 격자로 163종을 뽑아 도킹했다. 전체 순위상관은 −0.079 (95% CI −0.23~+0.08,
p=0.32) 로 신호가 없다. 탐색 깊이(4→128)와 프로토네이션(2×2)은 실험으로 원인에서
제외했고, 점수를 매긴 자세의 81% 가 2 Å 기준 밖이라는 사실이 모든 해석의 상한이다.

## 보존 — v2.0 (n=30, 대체됨)

`archive_v2/report_pde5.*` — 역가로만 층화한 30건에서 상관 −0.538 을 얻었던 판본.
더 큰 표본에서 재현되지 않았다. **v3.0 초안은 그 차이를 골격 교란으로 설명했으나, 옛
데이터에서 골격을 통제해도 감쇠가 1.2% 에 불과해 그 설명은 철회되었다** (v3.0 §3.5).
감사 추적을 위해 그대로 둔다.

## 판본이 바뀐 이력

| 판본 | 결론 | 무너진 이유 |
|------|------|-------------|
| v1.0 | "도킹은 역가를 예측하지 못한다" | 선별 지표를 하나도 계산하지 않았다 |
| v2.0 | "선별은 되고 정량은 안 된다" | 더 큰 골격 통제 표본에서 재현되지 않았다 |
| v3.0 초안 | "그 골격 편향이 원인이었다" | 검정해 보니 아니었다 (감쇠 1.2%) |
| v3.0 최종 | "재현되지 않았다. 원인은 화합물 집합" | — (현행) |

**세 번 모두 자동 게이트를 전부 통과했다.** 오류를 찾은 것은 매번 외부 비평 리뷰였다.
게이트는 수치가 산출되었는지·출처와 맞는지를 검사할 뿐, 결론이 데이터에서 따라 나오는지는
검사하지 못한다. 상세는 v3.0 본문의 §검증 로그와 §개정 이력에 있다.
