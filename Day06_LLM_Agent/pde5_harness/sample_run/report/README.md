# report — 심사를 통과한 보고서 고정본

`outputs/` 는 실행할 때마다 덮어써지므로 저장소에서 제외된다. 강의에서 읽을 수 있도록
최종본을 여기에 고정한다.

| 파일 | 내용 |
|------|------|
| `report_pde5.md` | IMRAD 본문 (수치는 원자료에서 스크립트가 주입) |
| `report_pde5.docx` | Word — 그림 6장 · 표 4개 삽입 |
| `report_pde5.pptx` | 발표용 9장 (한계 슬라이드 포함) |
| `report_pde5_doc.pdf` · `report_pde5_slides.pdf` | 위 둘의 PDF |
| `figures/` | PNG 6장 + 각 `.meta.json` (출처·해시·레코드 수) |

## 심사 이력

PI 리뷰 4회, Devil's Advocate 4회를 외부 에이전트로 매 회차 새로 호출했다.
최종 PI 9.4 / Devil 8/10. 통과 기준(9.7 / 10)에는 못 미쳤고, **그 사실과 이유를
`../REVIEW_LOG.md` 에 남긴 채 종결했다.** 점수를 맞추려 반복하는 대신 상한을
판정받고 수용한 것이다.

본문을 읽기 전에 `../REVIEW_LOG.md` 를 먼저 보면, 이 보고서가 어떤 지적을 받아
무엇을 고쳤는지 알 수 있다. 그 과정 자체가 이 자료의 교육 내용이다.
